# 同梱内容の検証

作成時に、サンプルのデータと作業フォルダを点検しました。

## 実施済み

- 6スキルの名前・description・YAML frontmatterをSkill Creatorの検証スクリプトで点検。
- 正本とClaude Code向けの12ファイルが一致することをSHA-256で比較。
- JSONの構文、必須ファイル、Markdown・HTMLのローカルリンク、CLAUDE.mdの取り込み先を検査。
- 試行データ：15件中12件が比較可能。合計240分・156分、差84分、削減率35.0%を再計算。
- 経費データ：全体7,140円＝候補3,740円＋確認待ち2,200円＋私用除外1,200円を照合。
- 使い捨てコピーで新規案件を作り、名前と目次への登録を確認。既存案件の上書きとフォルダ外へのパス指定を拒否することを確認。
- 同じコピーで、スキルの比較モード、正本からの同期、配布コピーの独自変更時の停止、独自スキルの保持を確認。
- 別セッションでprocess-meetingを実行。完成例を除いた原本のみから議事録・現在地・タスク・決定履歴を生成し、既存IDの維持、84分・35%の再計算、提案と決定の区別、期限未指定の維持を確認。

## 適用範囲

Claude Code／Codexの実アプリでの自動読み込み、認証・接続・sandbox・権限設定の実動作は未検証です。設定ファイルの構成は公式文書に沿っていますが、利用環境で確認してください。

HTMLは静的な構造とリンクを点検しました。ブラウザの表示を画像で確認する検証は、この環境に実行用ブラウザがないため未実施です。`summary.html`はローカルで開けるよう外部依存を入れていません。

証憑はダミーのメモのみで、本物のPDFや領収書、黒塗り処理の検証は対象外です。
