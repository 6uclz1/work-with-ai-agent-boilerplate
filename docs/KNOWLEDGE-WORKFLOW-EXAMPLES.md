# 新機能の使い方

最初は架空のサンプルや公開記事から試す。資料を実際に取得していない場合、記事を読んだことにしない。

## 1. Wikiへ取り込む

```text
capture-contextを使ってinboxのこの記事を整理して。
出典をsources/index.mdへ登録し、knowledge/wiki/INDEX.mdから関係するページだけ読んで統合して。
事実・推論・未確認と矛盾を区別して。判断やSkillはまだ変更しないで。
```

## 2. 比較検討の判断を残す

```text
この技術を導入するか、候補・評価軸・根拠・未確認をまとめて。
templates/decision-record.mdの形式でproposedの判断記録を作って。
採用の承認はまだ出していないので、acceptedにしないで。
```

## 3. 仕事からWorkflowを合成

```text
plan-workflowを使って、この記事の技術を小さく試すワークフローを作って。
過去のDecisionと関連Skillを使い、前提条件、成功基準、分岐、停止条件を明示。
ローカルで安全にできるところだけ進めて、承認が必要な操作は保留にして。
```

## 4. 実行結果で改善

```text
review-workflowで今回の実行結果と私の修正コメントを照合して。
評価記録、回帰ケース、差分案を作って。旧Skillと権限設定は勝手に変えないで。
承認が必要な点だけ報告して。
```

## 継続

`close-session` でhandoffと学びを記録し、次回は `handoffs/latest.md` を入口に再開する。評価からSkillへ反映する際は人間が提案差分を確認し、テスト・同期を行う。
