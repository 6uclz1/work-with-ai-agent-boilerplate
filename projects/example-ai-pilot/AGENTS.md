# サンプル案件の追加指示

- 全資料は架空。本人の実績・本物の社内規程として扱わない。
- 通常はproject、current、tasks、sources/indexを読む。再現練習ではREADMEが指定する会議前の原本を入力にし、完成例を入力に使わない。
- 調査・試行は15件、時間比較は12件。比較不能3件を時間削減率の分母へ混ぜない。
- 人数拡大・予算追加は提案と未決。決定済みの「次回まで5人で継続」と区別する。
- 日付は原本の絶対日付を使用する。実際の今週の報告へサンプルの日付を流用しない。
- 根拠はB1（前提）、C0（会議前の状態）、T0（旧タスク）、M1（会議）、N1（計測表）。
