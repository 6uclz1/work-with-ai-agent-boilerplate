# 会議の後処理

1. 仕事場と対象案件のAGENTS.mdを読み、保存先を特定する。通常は案件のmeetings/、current.md、tasks.md、decisions.mdを使う。練習の別保存先を指定されたらすべてそこへ出力する。
2. 会議前のcurrent・tasks・決定ログと、指定された原本を読む。サンプルの再現ではsources/raw/pre-meeting-current.mdとpre-meeting-tasks.mdを使い、完成例を入力にしない。
3. 文字起こしから事実・決定・提案・未決を分ける。固有名詞は既存の関係者情報と照合する。不明な担当・期限は未確認のまま残す。
4. templates/meeting-minutes.mdに沿って議事録を作り、各決定とタスクへ資料IDと見出しを付ける。単なる発言を合意扱いしない。
5. 旧状態との差分を整理し、currentを更新する。決定ログへ追加した根拠を残す。取り消された判断を黙って削除しない。
6. tasksの既存IDを維持し、新規項目へIDを付ける。重複を統合し、完了は報告された根拠で判断する。過ぎた期限だけで完了・取消にしない。
7. 原本と出力を照合し、数字・担当・期限・提案扱いを点検する。矛盾は確認事項へまとめる。
8. 変更した状態、未確認、次の一手を記録する。送信や共有は行わない。
