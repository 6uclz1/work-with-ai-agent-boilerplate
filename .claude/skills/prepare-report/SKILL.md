# 報告資料の前工程

1. 対象案件のAGENTS.md、current、tasks、sources/indexを読む。読み手・目的・判断してほしい事項・分量を既存情報から確認する。
2. 関係する原本を読み、成果、課題、リスク、次の行動、必要な判断に分ける。テンプレート内の架空情報を実務資料へ混ぜない。
3. 重要な主張へ資料ID・節を付ける。比較する数字の期間・単位・分母を揃える。不明な数字や古い資料の値を作って埋めない。
4. 外部調査が必要なら対象を絞り、一次情報のURL・確認日・発行日をresearchに残す。検索できないときは未調査としてローカル材料で進める。
5. outputs/summary.htmlまたはmaterial-summary.mdへ、材料を一覧できる1枚まとめを作る。HTMLはローカルで開ける自己完結形式とし、外部通信を入れない。
6. templates/report-outline.mdを使い、全体のタイトル・メッセージ・根拠・図表候補を一通り作る。各ページは一つの主張を中心にする。
7. 構成確認を依頼されているなら、まとめと骨子を揃えて人間の判断へ返す。清書まで許可されていれば全体を複数回見直し、必要な形式へ展開する。
8. 出力形式に適した見た目の確認を行い、templates/review-checklist.mdで原本・最新日付・未確認・公開範囲を点検する。読み込みに失敗した資料を明示する。
9. 引き継ぎと作業ログを残す。公開・提出は別の確定操作として扱う。
