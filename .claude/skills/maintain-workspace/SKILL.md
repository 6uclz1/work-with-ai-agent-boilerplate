# 育った仕事場を整理する

1. AGENTS、rules、work-map、skills-indexから入口と正本を確認する。全原本を無差別に読み込まず、対象を絞る。
2. 同じ約束の重複、矛盾、古い状態、実務と架空例の混在を点検する。消すべきと判断した理由と根拠を整理する。
3. currentとtasksの更新日を比較する。期限超過は確認項目にするだけで、勝手に取消・完了へ変えない。
4. 再利用手順の不足は適用範囲を限定して修正する。ルールが増える場合は古い同等の記述をまとめ、起動時の読み込みを増やしすぎない。
5. 完了案件は、依頼の範囲でarchiveへ移し、目次と根拠リンクを直す。未記録ファイルの削除や安全設定の変更は実施前に具体案を確認する。
6. scripts/sync_skills.py --checkとscripts/check_workspace.pyを実行する。違いがあれば正本と配布コピーのどちらに意図した変更があるか確認し、片側を無条件に潰さない。
7. 整理内容、残った問題、次の点検をlogsへ残す。サービス接続やスケジュールを勝手に追加しない。
