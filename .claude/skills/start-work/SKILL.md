# 相談から着手する

1. 仕事場のAGENTS.mdと共通ルールを読み、context/work-map.mdから対象を特定する。機密案件は一般の仕事場に取り込まない。
2. 雑な説明を「目的」「読み手・用途」「締切」「手元の材料」「未確認」に整理する。言い直しは最終の意図に合わせ、人名や金額は推測で訂正しない。
3. 初期設定ならcontext/profile.mdとpreferences.mdの未設定欄を見て、役割・定例業務・成果物・AIへ渡してよい範囲をまとめて質問する。回答済みの項目は再質問しない。
4. 新規案件ならtemplates/projectをprojects配下へコピーし、work-mapへ登録する。Pythonがあればscripts/new_project.pyも使える。既存フォルダを上書きしない。
5. 対象のAGENTS.mdを開き、原本をsources/rawに保持する。依頼文を保存するときは取得日と出どころを添え、sources/index.mdへ登録する。
6. ローカルでできる整理や下書きを進める。判断を変える不明点だけを一度にまとめて聞く。接続がなくてもコピペ用の準備を作る。
7. 終了時にclose-sessionの手順で状態と引き継ぎを残す。
